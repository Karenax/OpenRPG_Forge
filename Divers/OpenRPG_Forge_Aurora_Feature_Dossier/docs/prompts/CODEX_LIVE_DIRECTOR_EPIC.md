# Prompt Codex — préparer Live Director

Ne commence ce travail qu’après disponibilité d’un serveur autoritaire et d’un système de commandes/audit.

Lire le domaine DM, MULTI, `LIVE_DIRECTOR_SECURITY.md` et la matrice d’événements.

Premier objectif seulement :

- rôle GM authentifié ;
- player/world chooser read-only ;
- inspect entity ;
- teleport spectator camera ;
- audit de toutes les actions.

Ne pas implémenter possession, exécution de scripts, modification de progression ou spawn massif dans le premier incrément.
