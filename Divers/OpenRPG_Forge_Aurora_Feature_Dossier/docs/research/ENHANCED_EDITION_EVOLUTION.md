# Recherche — évolution Enhanced Edition

L’Enhanced Edition a fait évoluer la plateforme pendant plusieurs années. Les capacités pertinentes pour Forge sont regroupées ici par intention.

## Toolset

- transformations et mise à l’échelle ;
- onglets de zones multiples ;
- raccourcis et amélioration de l’inventaire ;
- optimisation du build/update ;
- corrections de l’historique undo.

## Rendu

- PBR ;
- tone mapping et éclairage par pixel ;
- davantage de lumières dynamiques ;
- eau améliorée ;
- LOD ;
- options modernes d’anti-aliasing et filtrage.

## Données et scripting

- règles plus data-driven ;
- classes de lanceurs personnalisées ;
- JSON ;
- sérialisation d’objets ;
- commandes de resource manager ;
- création dynamique de zones et copie d’objets ;
- transformations interpolées.

## UI

- NUI scriptable ;
- événements GUI ;
- TrueType ;
- scaling UI ;
- requêtes de périphériques ;
- indicateurs de ciblage AOE.

## Distribution et opération

- contenu curaté ;
- NWSync et métadonnées de repository ;
- améliorations réseau et pathfinding ;
- logs, profiler Tracy et qualité de vie du compilateur/Toolset.

Forge ne doit pas reproduire les limites numériques exactes de NWN. Il doit reprendre la capacité et définir des budgets par plateforme.
