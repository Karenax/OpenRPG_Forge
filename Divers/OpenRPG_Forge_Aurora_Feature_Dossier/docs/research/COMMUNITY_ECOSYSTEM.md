# Recherche — écosystème communautaire

## NWNX:EE

Montre les besoins des persistent worlds : extensions serveur, base de données, hooks, administration et fonctions non disponibles initialement. Forge prévoit un SDK serveur versionné, mais après le vertical slice et le serveur autoritaire minimal.

## Nasher et neverwinter.nim

Montrent l’importance de sources textuelles, builds CLI, Git, compilateur ouvert et maintenance de repositories de contenu. Ces besoins sont fondamentaux dès Gate 0 de Forge.

## NeverBlender

Montre qu’un Toolset de gameplay ne remplace pas un DCC. Forge doit intégrer Blender comme outil externe, avec GLB, validation, collisions, LOD et provenance.

## Radoub

Montre la valeur d’éditeurs de ressources modernes, cross-platform, accessibles, avec navigateur et project hub. Forge doit éviter d’enfermer toutes les tâches dans une vue 3D.

## Frameworks d’événements

Les persistent worlds ont construit des bus d’événements par-dessus NWScript. Forge doit fournir ce contrat nativement, typé, traçable et compatible serveur.
