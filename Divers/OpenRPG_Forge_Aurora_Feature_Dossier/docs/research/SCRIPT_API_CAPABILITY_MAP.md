# Recherche — familles de capacités NWScript

Le Lexicon classe l’API historique en nombreuses familles : actions, alignement, animations, zones, combat, caméra, cutscenes, base de données, debug, effets, encounters, objets, compagnons, inventaire, propriétés d’items, journal, éclairage, variables, math, module, monnaie, mouvement, musique, party, joueurs, perception, réputation, sauvegardes, serveur, sons, sorts, SQL, magasins, strings, compétences/dons, temps, traps, conversions, VFX, JSON, NUI et ressources.

Cette liste sert de **carte de couverture**, pas de spécification à copier. ForgeScript utilisera des noms, types, règles de sécurité et contrats originaux. La matrice détaillée est dans `tracking/SCRIPT_CAPABILITY_MATRIX.csv`.
