# Pipeline de contenu

```text
source externe
    ↓ quarantaine
inspection + licence + provenance
    ↓ import profile
conversion GLB/textures/audio
    ↓ validation technique
LOD/collision/navigation/metadata
    ↓ catalogue Forge
package + hashes + notices
```

## Blender

Blender reste le DCC. Le Toolset ne tente pas de recréer la modélisation complète. Le bridge expose des opérations bornées et peut fonctionner headless.

## Assets communautaires

Aucun pack n’est intégré globalement sur la seule base de sa présence sur le Vault ou dans le CEP. Chaque ressource exige une licence inter-moteur compatible et une provenance.
