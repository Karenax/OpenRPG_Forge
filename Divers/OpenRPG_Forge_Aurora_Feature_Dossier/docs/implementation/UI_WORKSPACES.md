Les workspaces sont fournis par Core ou Kits. Ils partagent sélection, commandes, diagnostics, historique et recherche.

## Beginner mode

Le profil débutant masque les propriétés avancées et propose des assistants sans supprimer les données. Le mode avancé expose les composants et contrats complets.

## Accessibilité

Toutes les actions essentielles ont une commande, un raccourci configurable et un libellé. La couleur n’est jamais l’unique indicateur d’état.
