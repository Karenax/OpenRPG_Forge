# forge_core

Contrats métier minimaux et indépendants du moteur : identités persistantes, révisions monotones,
repère mètres/Y-up/droitier, transform, empreinte SHA-256 d'un JSON canonique et distribution de
frame times versionnée (moyenne, p95 nearest-rank, 1 % low et histogramme exhaustif).

Cette crate ne dépend ni de Bevy, ni de Tauri, ni d'une API graphique.
