# forge_assets

Contrats génériques d'identité, de provenance, d'importation et de validation
des assets Forge. Aucun paquet, snapshot ou recette d'une carte nommée ne fait
partie de cette crate.

Les importeurs fournissent les octets, les paramètres et les manifestes à
valider. Une validation de transport ne qualifie pas leur apparence dans le
renderer. Les documents persistants restent indépendants de Bevy.
