# Forge Forest Map — notices tierces

## Godot Procedural Forest Demo et gnd_biomes

Le cœur de scatter de ce module est adapté de **Godot Procedural Forest Demo** par
GamesNotDeveloped :

- source : https://github.com/GamesNotDeveloped/godot-forest-demo ;
- commit intégré : `623212ffeb4efbf4c95323a4a6a57e726be4f6e9` ;
- licence : Creative Commons Attribution 4.0 International ;
- texte complet : `licenses/godot-forest-demo-CC-BY-4.0.txt`.

Modifications Forge : renommage et isolation des types, masque multicanal, exclusion des zones
interdites, définition JSON versionnée, panneau de peinture français, branchement à l’Asset Vault,
scène de création et smoke test.
