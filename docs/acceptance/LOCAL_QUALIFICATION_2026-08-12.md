# Qualification locale du 12 août 2026

## Environnement

- Windows x64 ;
- AMD Radeon RX 7800 XT ;
- rendu Forward+ ;
- moteur embarqué 4.7.1 .NET ;
- captures runtime : 1280 × 720 ;
- Creator revu en fenêtre normale puis maximisée.

## Revue interactive

- le Creator s'ouvre sous la marque OpenRPG Forge ;
- les outils spécialisés s'ouvrent dans une fenêtre embarquée, non exclusive et redimensionnable ;
- la navigation principale, le panneau de sélection et les détails techniques repliés restent lisibles ;
- Crypte des Cendres démarre, affiche le kit artistique CC0 et accepte les commandes de déplacement
  et d'interaction ;
- Forgotten Forest affiche les personnages, le HUD, les objectifs et les arbres stylisés sans les
  cubes auxiliaires issus de Blender.

## Distribution

- Runtime et Creator reconstruits et vérifiés depuis leurs exécutables autonomes ;
- 38 composants et 38 licences présents dans chaque dossier de conformité ;
- installateur NSIS testé sur un profil AppData temporaire vide ;
- installation, smoke, mise à jour sur place et désinstallation réussis ;
- données utilisateur externes au dossier d'installation préservées ;
- signature constatée : `NotSigned`.

## Limites de cette qualification

Cette revue ne choisit pas la licence du code du dépôt et ne peut pas produire un certificat
Authenticode. Le test physique sur un second écran et l'UX d'un fournisseur IA réel restent à rejouer
avant une release publique. Ils ne remettent pas en cause le prototype local, les parcours automatisés
ni la distribution de développement.
