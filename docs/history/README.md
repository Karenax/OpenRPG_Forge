# Archives de livraison

Ce dossier conserve les journaux détaillés des gates, lots et preuves historiques. Ils restent utiles
pour la traçabilité, mais ne constituent pas la file active et leurs anciennes mentions de
« prochaine tranche » ne doivent pas guider une nouvelle intervention.

Les sources opérationnelles courantes restent `STATUS.md`, `TASKS_MVP.md`, le tracker Aurora et le
registre généré `docs/planning/COMPLETE_FUNCTION_BACKLOG.md`.
