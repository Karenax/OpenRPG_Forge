# G13-R — Triggers : découverte et accès

Features : `ORF-TRG-005`, `ORF-TRG-008`, `ORF-TRG-012`, `ORF-TRG-013`, `ORF-TRG-014`.

## Livré

Le profil de trigger combine sens et difficulté de découverte, portée de révélation, verbe/cursor/
outline/prompt, script de clic, permission, identifiant requis et feedback de refus. Un volume de
repos déclare sécurité, groupe complet, danger et messages accessibles.

## Preuves

- test : `G13R_TriggerDiscoveryAccess_RequiresDiscoveryCredentialAndPermission` ;
- Toolset/runtime : `G13R_TRIGGER_DISCOVERY_ACCESS_PASS` et `G13R_TRIGGER_ACCESS_PASS`.

Limite : le système de perception fournit le score ; le profil ne le calcule pas.
