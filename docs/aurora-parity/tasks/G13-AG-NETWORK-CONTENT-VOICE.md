# G13-AG — Contenu réseau et voix

Features : `ORF-MP-014`, `ORF-MP-021`.

Le profil réseau relie contenu sélectionné vérifié et voix optionnelle avec bitrate, canal et
consentement. Aucun service vocal ou téléchargement distant n'est requis par le runtime local.

Preuves : `G13AG_NetworkContentAndVoice_StayOptionalAndGoverned` et marqueurs
`G13AG_NETWORK_CONTENT_VOICE_PASS`.
