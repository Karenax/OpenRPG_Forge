# G13-AF — Groupes et enregistrement de session

Features : `ORF-DM-022`, `ORF-DM-037`.

Les groupes sauvegardés associent requête, raccourci et plafond de membres. L'enregistrement exige
permission d'observation, identité injectable, format export explicite et expurgation des données privées.

Preuves : `G13AF_Recording_ResolvesSavedGroupsAndPrivacyPolicy`, `LiveProductionServiceTests` et
marqueurs `G13AF_DIRECTOR_RECORDING_PASS`.
