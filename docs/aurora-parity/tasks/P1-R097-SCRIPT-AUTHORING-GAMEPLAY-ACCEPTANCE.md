# R097 — Script authoring and gameplay APIs acceptance

## Scope

`R097 / FC-SCRIPT-P1-01` closes exactly five P1 functions:

- `ORF-SCR-004` — script editor;
- `ORF-SCR-005` — Script Wizard;
- `ORF-SCR-008` — deferred action API;
- `ORF-SCR-010` — combat API;
- `ORF-SCR-011` — effect API.

The source criteria were read in full from
`Divers/OpenRPG_Forge_Aurora_Feature_Dossier/docs/requirements/18_SCRIPT.md` at lines 301–375,
377–451, 605–679, 757–831 and 833–907.

## Dependency reduction

SHELL contributes the existing ForgeScript editor window and its transaction boundary. DIALOGUE and
QUEST consume reviewed Wizard source but retain ownership of their canonical documents. GAMEPLAY
contributes server authority and runtime state. CREATURE and ITEM remain opaque entity/data handles;
R097 does not duplicate their catalogs. The lot reuses `ForgeScriptSourceHistory`, the native
AngelScript sandbox, `ForgeScriptAuthoringService` and `ScriptGameplayService`.

## Shared acceptance

- `ForgeScriptSourceDocument` remains the canonical UUID/schema/provenance/API/event document;
  generated bytecode and engine nodes remain disposable projections.
- `ForgeScriptSourceHistory` remains the only editor mutation boundary, with preview, apply,
  rejection, Undo/Redo and atomic source/metadata persistence.
- Missing optional P1 script data is ignored; required use returns
  `FORGESCRIPT_P1_REQUIRED_MISSING`; stale handles are rejected.
- Native `ScriptTaskRef`, `EffectHandle` and entity handles are opaque and generation-checked; all P1
  gameplay calls remain inside the same quota-limited sandbox.
- MCP obtains the same versioned signatures and can compile/test the native calls without shell,
  file, network or engine-object access.

## Delivered bounded changes

- Completed editor analysis, identified Script Wizard validation and deterministic task lifecycle.
- Added versioned native action/combat/effect calls and rebuilt the pinned AngelScript bridge.
- Completed armor-aware combat, periodic effects and serializable effect snapshots in the RPG Kit.
- Added one application adapter and one accessible runtime panel over the existing services.
- Exposed authoring/gameplay summaries, deterministic formatting and Wizard insertion in the existing
  ForgeScript editor; no parallel source editor was created.
