# Téléchargements nécessitant une action manuelle

Date de vérification : 2 août 2026.

## Quaternius

Les pages exactes vérifiées déclarent les packs CC0, mais leurs téléchargements ne fournissent pas
une URL d’archive directe stable adaptée au pipeline automatique :

- Stylized Nature MegaKit : plus de 110 modèles, téléchargement gratuit via Itch.io ;
- Medieval Village Pack : 44 modèles, téléchargement via un dossier Google Drive partagé.

Conformément aux règles du projet, le pipeline ne simule pas une validation Itch.io, ne contourne pas
une page de téléchargement et ne devine pas l’URL interne d’un fichier Google Drive. Télécharger
manuellement depuis la page officielle, puis déposer l’archive intacte dans
`E:\OpenRPG_AssetVault\originals\quaternius\<pack-id>\`. Un futur adaptateur de pack manuel devra
calculer SHA-256, conserver la page/preuve CC0 et extraire avec les mêmes contrôles que les autres
sources.

Ce mode manuel et les catégories explicitement refusées sont gouvernés par
`docs/assets/ASSET_SOURCE_GOVERNANCE.md`.

- https://quaternius.com/packs/stylizednaturemegakit.html
- https://quaternius.com/packs/medievalvillage.html
